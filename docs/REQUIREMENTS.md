# 요구사항 정의서 (Software Requirements Specification)

**프로젝트명**: Perfect Ring Toss
**버전**: 1.0
**작성일**: 2026-01-16

---

## 1. 개요

### 1.1 목적
본 문서는 Perfect Ring Toss 게임의 기능적/비기능적 요구사항을 정의한다.

### 1.2 범위
- 웹 기반 캐주얼 링 던지기 게임
- 솔로 모드 및 온라인 멀티플레이어 모드 지원
- Render 플랫폼 배포

### 1.3 용어 정의
| 용어 | 설명 |
|------|------|
| 링 (Ring) | 플레이어가 던지는 도넛 모양 오브젝트 |
| 바 (Bar) | 링을 걸어야 하는 수직 막대 |
| 대기열 (Queue) | 온라인 모드에서 플레이 순서를 기다리는 목록 |
| 관전자 (Spectator) | 대기열에 있거나 관전만 하는 사용자 |

## 3. 비기능 요구사항 (Non-Functional Requirements)

### 3.1 성능

| ID | 요구사항 | 기준 |
|----|----------|------|
| NFR-001 | 게임 프레임 레이트 | 최소 30 FPS, 목표 60 FPS |
| NFR-002 | 초기 로딩 시간 | 3초 이내 (캐시 후 1초 이내) |
| NFR-003 | Socket.io 지연 시간 | 100ms 이내 |
| NFR-004 | API 응답 시간 | 500ms 이내 |

### 3.2 호환성

| ID | 요구사항 | 지원 범위 |
|----|----------|-----------|

| NFR-011 | 모바일 브라우저 | iOS Safari, Android Chrome |
| NFR-012 | 최소 해상도 | 320px (모바일) |
| NFR-013 | 권장 해상도 | 1280px 이상 |

### 3.3 가용성

| ID | 요구사항 | 설명 |

| ID | 요구사항 | 설명 |

## 5. 제약사항

### 5.1 기술적 제약
- Render 무료 플랜 사용 (15분 비활성 시 슬립)
- PostgreSQL 무료 플랜 사용
- 프레임워크 없이 Vanilla JavaScript 사용

### 5.2 비즈니스 제약
- 복잡한 난이도 시스템 없음 (단일 난이도)
- 콤보/보너스 시스템 없음
- 인앱 결제 없음
