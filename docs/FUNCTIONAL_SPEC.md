## 2. 기능 상세

### 2.1 게임 코어 엔진

#### 2.1.1 캔버스 렌더링
```
┌─────────────────────────────────────┐
│          Canvas (800x600)           │
├─────────────────────────────────────┤
│                                     │
│  발사점(●)          바(|)           │
│  x: 100            x: 650           │
│  y: 500            y: 200~450       │
│                                     │
│  링(○)                              │
│  반지름: 30px                        │
│  두께: 8px                          │
│                                     │
└─────────────────────────────────────┘
```

**렌더링 사이클**
```javascript
function gameLoop() {
    clear();           // 화면 초기화
    updatePhysics();   // 물리 업데이트
    checkCollision();  // 충돌 감지
    render();          // 렌더링
    requestAnimationFrame(gameLoop);
}
```

#### 2.1.2 바 (Bar) 오브젝트
| 속성 | 값 | 설명 |
|------|-----|------|
| x | 650 | 고정 X 좌표 |
| y | 200 | 상단 Y 좌표 |
| height | 250 | 바 높이 |
| width | 10 | 바 두께 |
| baseWidth | 60 | 받침대 너비 |

**렌더링**
```
     │  ← width: 10px
     │
     │  ← height: 250px
     │
   ━━┻━━ ← baseWidth: 60px
```

#### 2.1.3 링 (Ring) 오브젝트
| 속성 | 타입 | 설명 |
|------|------|------|
| x | number | 현재 X 좌표 |
| y | number | 현재 Y 좌표 |
| vx | number | X 속도 |
| vy | number | Y 속도 |
| radius | number | 외부 반지름 (30px) |
| innerRadius | number | 내부 반지름 (22px) |
| rotation | number | 회전 각도 (rad) |
| state | enum | 'ready' | 'flying' | 'success' | 'fail' |

#### 2.1.4 물리 엔진
**포물선 운동 공식**
```
vx = power * cos(angle)
vy = power * sin(angle)

// 매 프레임
x += vx * dt
y += vy * dt
vy += gravity * dt  // gravity = 980 px/s²
rotation += rotationSpeed * dt
```

**입력 → 발사 변환**
```
드래그 시작점: (startX, startY)
드래그 끝점: (endX, endY)

dx = startX - endX
dy = startY - endY

angle = atan2(dy, dx)
power = min(sqrt(dx² + dy²) * 2, MAX_POWER)
```

#### 2.1.5 충돌 감지
**성공 조건**: 링의 중심이 바를 통과하며, 링의 내부 반지름이 바를 감쌀 때

```
성공 판정 영역:
┌─────────────────┐
│       │         │
│   ○───┼───○     │  ← 링이 바를 감싸는 상태
│       │         │
└─────────────────┘

조건:
1. ring.x - innerRadius < bar.x < ring.x + innerRadius
2. ring.y > bar.y (바 상단 아래)
3. ring.y < bar.y + bar.height (바 하단 위)
4. ring.vy > 0 (하강 중)
```

**실패 조건**
- 링이 화면 밖으로 나감 (y > canvas.height)
- 링이 바를 스쳐 지나감 (충돌 없이 통과)

### 2.3 온라인 멀티플레이어 모드

#### 2.3.1 대기열 시스템
```javascript
// 서버 측 GameManager 구조
class GameManager {
    queue = [];          // 대기열 [{socketId, nickname}, ...]
    currentPlayer = null; // 현재 플레이어
    spectators = new Set(); // 관전자

    addToQueue(socketId, nickname) { ... }
    removeFromQueue(socketId) { ... }
    nextTurn() { ... }
    getCurrentState() { ... }
}
```

**대기열 흐름**
```
[새 유저 접속]
      │
      ▼
[닉네임 입력] ──→ join-queue 이벤트
      │
      ▼
[대기열 맨 뒤에 추가]
      │
      ▼
[queue-update 브로드캐스트]
      │
      ▼
[현재 플레이어 관전 중...]
      │
      ▼
[현재 플레이어 실패]
      │
      ▼
[대기열 첫 번째 유저에게 your-turn 전송]
      │
      ▼
[플레이 시작]
```

#### 2.3.2 실시간 동기화
**링 위치 중계 주기**: 60fps (약 16.67ms)

```
[플레이어]                    [서버]                    [관전자들]
    │                           │                           │
    │ throw-ring               │                           │
    │ {angle, power}           │                           │
    │ ────────────────────────→│                           │
    │                           │ ring-update              │
    │                           │ {x, y, rotation}         │
    │                           │──────────────────────────→│
    │                           │                           │
    │                           │ (매 프레임 반복)          │
    │                           │──────────────────────────→│
    │                           │                           │
    │ throw-result             │ throw-result              │
    │ {success, score}         │ {success, score}          │
    │ ←────────────────────────│──────────────────────────→│
```

#### 2.3.3 연결 해제 처리
| 상황 | 처리 |
|------|------|
| 대기 중 연결 해제 | 대기열에서 제거, queue-update 브로드캐스트 |
| 플레이 중 연결 해제 | 강제 탈락 처리, 다음 플레이어로 턴 이동 |
| 관전 중 연결 해제 | spectator-count 업데이트 |

### 2.4 리더보드 시스템

#### 2.4.1 데이터베이스 스키마
```sql
CREATE TABLE scores (
    id SERIAL PRIMARY KEY,
    name VARCHAR(20) NOT NULL,
    score INTEGER NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP

CREATE INDEX idx_scores_score ON scores(score DESC);
CREATE INDEX idx_scores_name ON scores(name);
```

## 3. 에러 처리

### 3.1 클라이언트 에러
| 에러 | 원인 | 처리 |
|------|------|------|
| 캔버스 미지원 | 구형 브라우저 | 안내 메시지 표시 |
| WebSocket 연결 실패 | 네트워크 오류 | 재연결 시도 (3회) |
| 서버 응답 없음 | 서버 슬립 | 로딩 표시 + 자동 재시도 |

### 3.2 서버 에러
| 에러 | 원인 | 처리 |
|------|------|------|
| DB 연결 실패 | PostgreSQL 오류 | 로그 기록, 503 응답 |
| 비정상 점수 | 치팅 시도 | 점수 무시, 로그 기록 |
| 대기열 오버플로우 | 과다 접속 | 대기열 제한 (1000명) |
